# Momcozy GEO 试点：复测与报告讨论基线

> **状态：L0 讨论基线，2026-11-08。** 用户同意先设计内部报告模板和可比性检查，展示数据覆盖、诊断、内容审核状态及阻断项；未来具备授权与数据后再报告复测结果。具体指标、问句、报告格式、责任人、采样执行与签发方式仍待确定。此同意不授权真实数据访问、采样、复测、报告签发或发送、飞书接入、开发、部署和发布。

## 1. 报告应回答的问题

| 板块 | 建议展示 | 限制 |
|---|---|---|
| 范围与状态 | 品牌、市场/语言、品类、目标问题、数据截止、报告用途及状态 | 没有可用数据时写“暂无可判断数据”，不写成零或品牌未被提及。报告草稿不等于正式签发。 |
| 数据来源与覆盖 | 按来源轨道、平台/产品面、窗口和问句集分别说明；对实际计划报告各状态、失败、无效及未执行 | 无计划时不虚构 `planned`；不能把不同轨道或不同定义的数据合并成一个 GEO 总分。 |
| 观察与诊断 | 可判断的结果、可定位依据、未知、限制和原因假设；比率展示分子分母 `x/n` | 观察、事实判断、假设及建议分开；模型回答不自动证明商品事实。 |
| 内容与候选 | 内部候选是否待审、确认或驳回；适用时列出 FAQ 草稿与人审状态、未核事项 | 候选确认不等于派单或执行；内部草稿审核不等于实际发布。若没有实际记录，标未创建或未知，不推断。 |
| 复测与变化 | 分别列出各期完整样本与共同核心问句子集、分母、失败和未知，标出新增/移除及条件变化 | 分母为零的指标为 N/A；共同核心为空不能做匹配比较；样本不足或协议不可比时不输出误导性变化。 |
| 阻断及待办 | 缺失事实、权限、数据、预算或负责人，以及拟议的下一人工动作 | 阻断限定于受影响的指标、声明或用途；拟议动作不是已派单、执行或授权。 |

各板块是建议，不是已冻结的字段、权限模型、审批角色或产品界面。报告签发、查看、共享、导出和对外发布须分别核验授权，报告内部审核通过不自动授权其他操作。

## 2. 复测的最小可比性检查

在未来执行获授权后，建议按指标及适用层次分别核查：

1. **来源和范围**：两期的来源轨道、平台/产品面、市场、语言和时间窗口定义；不能把 API 代理、平台聚合或其他轨道冒充消费端观察。
2. **问题与计划**：预先定义共同核心问句，保留问题原文与版本、品牌显式性、适用性、重复及执行规则。新增、移除或修改的问题单列；同一共享回答关联多个 ASIN 不重复计入品牌回答级分母。
3. **环境和判定**：对照入口、模式、账号/设备策略、标注、品牌别名、官方来源映射及指标版本；平台/UI/模型等已知变化和未知项也需记录。未知不默认视为一致。
4. **覆盖和分母**：各期分别展示有效、失败、无效、未执行及指标层的未知；以共同子集与各期完整集合分开呈现，不能静默删除流失项目或将 unknown 当负例。
5. **结论**：检查通过时，仍只描述该协议、样本和窗口内的差异。若条件差异影响比较或证据不足，应分期展示并解释原因；不得自动声称平台整体变化、统计显著性或由某次内容修改造成结果。

问句、标注、样本量、比较细则和允许的报告用途尚须业务及相应 owner 评审；不预设固定样本数量、相同文本以外的语义等价性或未经批准的跨轨道桥接。详见[问句、采样与指标讨论稿](./2026-11-08-geo-sampling-metrics-discussion.md#62-复测与比较门禁)。

## 3. 截止时状态和缺失值

仅在实际冻结了采样计划时，建议沿用采样讨论稿中的守恒：

```text
planned = not_run + in_progress + failed + invalid + valid_answer + valid_no_feature
```

`planned` 是计划总数，不是互斥状态；`not_run` 和 `in_progress` 是合法截止状态，不自动算失败。`valid_no_feature` 仅在该入口及目标功能适用且可确认时使用，可用于对应功能未触发指标，但不是“品牌未被提及”的有效答案。指标层 `judgeable / unknown / not_applicable` 另行按口径记录，不混入计划项状态。

无品牌发现的指标口径尚待业务审核：候选为在预先批准的无品牌发现题中，实质提及品牌的可判断有效回答数 / 同层可判断有效回答数。失败、未触发和 unknown 不当作未提及。无有效可判断分母则为 N/A，而不是 0%；与引用声明支持度及型号事实准确率的计数单位分别处理。

## 4. 当前状态与许可

- 当前没有经本项目独立核实、可按拟定协议复测的基线；PMO 页面上的历史小样本陈述与其他历史观察不能直接视为该基线。历史数据若拟再利用、分享或送模型，先分别核验来源、权利和用途。
- Perplexity 消费端系统性商业采样、复制、截图及导出仍为 **HOLD**；须核验适用协议、必要许可、法务判断及项目执行授权。人工操作或简化记录不是许可替代。
- 没有真实复测数据时可讨论中性报告结构或明确标示的合成示例，但不冒充 Momcozy 实际表现。合成示例、报告讨论状态和真实数据权限不能相互替代。
- 不要求先完成第二次采样才审核内部草稿。未来若需比较内容处理前后效果，须另行核对实际处理、观察窗口、采样许可、计划及执行授权；即使出现变化也不自动归因。

本文件是讨论记录，不代表已进行采样、复测、真实数据处理、签发、发送、开发或验收。总方案和既有资产核验顺序见[总体计划](./2026-11-08-geo-agent-workbench-master-plan.md)。
