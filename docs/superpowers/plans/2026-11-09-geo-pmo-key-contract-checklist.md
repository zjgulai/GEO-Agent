## 1. 术语约定

下列词是**我方的分析标签**，不要求 PMO 采用；请用贵方字典的命名回答，我方再做映射。

| 我方标签 | 含义 |
|---|---|
| 计划项 | 冻结计划全集中的一项；其状态另按六态记录，"计划项"本身不是状态 |
| 执行尝试 | 对同一计划项的一次实际执行 |
| 一次答案 | 一次观察得到的回答记录 |
| 答案版本 | 同一逻辑答案因重渲染、纠错或模型变化形成的不同版本 |
| 渲染结果 | 最终展示给观察者的界面结果 |
| 采集 | 抓取或导入形成的一条原始记录 |

**两个固定前提（不再询问，也不会因答复而改变）：**

1. `ai_answer_snapshot_id` **不是**商品事实主键，也不等同于 `FactVersion`。
2. 答案不等于事实。快照可关联只证明系统在某时记录了该回答，不证明内容为真。

**我方处理原则：** 未回答、不确定或未定义 → 记 `unknown`，不按名称、前缀、长度或常识推断；依赖该问题的用途 → `HOLD`；不依赖的问题与其他工作不受阻断。

## 8. 发送时应附说明

1. **用途**：仅用于 T5 交接契约的纸面核验与后续数据模型对齐。
2. **范围**：纸面问答；不需要凭证、导出或接口调用；如需查看元数据，仅在 AUTH-02 指定范围内，且 T5 覆盖需另行确认。
3. **预期产出**：一份填空后的 T5 与 unknown 清单，不是集成方案。
4. **我方承诺**：未获明确授权前不复制、不导出、不截图、不送模型、不写入原系统、不对外引用。
5. **回答方式**："不确定""尚未定义""不适用"都是有效回答，不需要猜测；如需其他 owner 确认，给出责任角色即可。

## 9. 核对完成判据

以下同时满足，才可把状态从 `unknown` 调整为"纸面契约已核对"：

- Q1–Q36 均有明确回答，或显式 `unknown` / 经确认的 `not_applicable`；
- 回答标明适用系统/环境、日期与复核责任；
- 未确认项已登记影响范围、责任角色与下一动作；
- 明确纸面评审不等于接口验证、资产验收或事实批准。

**样例为可选项，但影响下游判定**：本清单**不索取样例**。若 owner 愿意提供，优先使用合成或脱敏数据；脱敏样例仍需 owner 明确许可，且不构成复制、导出或截图授权。无样例时以字段级书面说明替代。

注意：本清单的"纸面契约已核对"**不等于**复用评估第 8 维（版本与主键契约）`pass`。该维最低证据包含样例与签发方确认；无样例时只能记 `partial` 或 `unknown`，除非 ADR 明确记录豁免理由。

## 10. 明确不假设的事项

- 不假设标识全局唯一、不可变或任何特定格式。
